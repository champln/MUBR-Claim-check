จะต้องมี module หลักดังนี้
- RBAC ล็อคอิน กำหนดสิทธิ์
- master claim data สำหรับสร้าง rule ใช้ในการตรวจสอบโดยจะต้องทำความเข้าใจเอกสาร pdf ไฟล์ excel,csv และ manual สร้างกฏการตรวจสอบได้ 
- realtime or Async data screen เชื่อมต่อฐานข้อมูลระบบ hosxp xe ทำความเข้าใจโครงสร้างตารางข้อมูลไหนทำอะไร อ่านค่า เช็คในตารางที่เกี่ยวข้องกับการบันทึกข้อมูลการส่งเบิก เช่นตารางค่าใช้จ่าย opitemrece ตาราง การลงรหัสโรค ovstdiag ตารางการจ่ายยา opi_dispense เป็นต้น โดยจะต้องแปลงกฏจาก master claim data มาเป็น query เพื่อตรวจสอบข้อมูลที่บันทึก realtime ในวันเพื่อแจ้งเตือน การบันทึกข้อมูลผิดเงื่อนไข ก่อนที่จะมีการปิดค่าใช้จ่าย
- file claim data check & correction ตรวจสอบไฟล์ส่งเบิกที่ export มาแล้วจาก hosxp chi export,hosxp eclaim export เพื่อตรวจสอบเงื่อนไขการติด C หรือ ไม่ตรงเงื่อนไขการเบิกของศูนย์การแพทย์ เพื่อตรวจสอบก่อนส่งไฟล์เบิกที่กองทุน และสามารถคลิกแก้ไขได้ทุกฟิลด์
